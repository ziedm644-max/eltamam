# منصة مستر إبراهيم التمام

## التشغيل
1. نزّل Node.js (إصدار 18 أو أحدث) من nodejs.org
2. افتح الفولدر في VS Code وفي الـ Terminal شغّل:  node server.js
3. افتح  http://localhost:3000

## الموبايل
افتح من الموبايل (نفس الواي فاي) العنوان اللي بيظهر في الـ Terminal.
